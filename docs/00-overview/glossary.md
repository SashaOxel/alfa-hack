# Глоссарий

## Бизнес и банк

| Термин | Расшифровка / смысл |
|---|---|
| **ММБ** | Малый и микробизнес. Сегмент банка: ИП и небольшие ООО |
| **МСП** | Малое и среднее предпринимательство. Юридическая категория (209-ФЗ), фиксируется в **Реестре МСП** ФНС: микро (до 15 чел., до 120 млн ₽ выручки в год), малое, среднее |
| **ИП / ООО** | Индивидуальный предприниматель / общество с ограниченной ответственностью. Важно: **ИП отвечает по долгам всем личным имуществом**, поэтому для ИП смотрим и на личную кредитную историю владельца |
| **ИНН, ОГРН / ОГРНИП** | Идентификаторы налогоплательщика и записи в госреестре |
| **ОКВЭД** | Код вида деятельности (например, 56.30 — подача напитков). Определяет отраслевой риск, сезонность, допуск к госпрограммам |
| **РКО** | Расчётно-кассовое обслуживание, то есть расчётный счёт бизнеса. Главный источник данных |
| **Обороты** | Все поступления на счёт: выручка + займы + переводы между своими счетами + возвраты. **Не равно выручке** |
| **Выручка** | Поступления от продажи товаров и услуг: эквайринг, СБП, оплаты от покупателей, выплаты маркетплейсов |
| **Доля выручки в оборотах** | `выручка / обороты`. Низкая доля — признак транзитных операций (риск по 115-ФЗ) |
| **Остаток на счёте** | Баланс на дату. Смотрим средний, минимальный и число дней с низким остатком |
| **Кредитная нагрузка** | У нас: `сумма ежемесячных платежей по всем долгам / среднемесячная выручка`. Альтернативная метрика: `общий долг / годовая выручка` |
| **DSCR** | Debt Service Coverage Ratio: `свободный денежный поток / платежи по долгу`. Норма ≥ 1,25 |
| **FCF** | Free Cash Flow: свободный денежный поток. У нас: операционные поступления минус операционные платежи за месяц |
| **Кассовый разрыв** | Момент, когда на счёте не хватает денег на обязательные платежи |
| **PD** | Probability of Default: вероятность дефолта (просрочки 90+ дней) в горизонте 12 месяцев |
| **Скоринг** | Модель, которая оценивает риск клиента |
| **Pre-approved / предодобренное предложение** | Оффер, который банк рассчитал заранее по данным клиента, без заявки |
| **Стоп-фактор** | Условие, при котором продукт не выдаётся независимо от скора (банкротство, блокировка счёта ФНС и т.п.) |
| **Овердрафт** | Кредитный лимит к расчётному счёту: можно уйти в минус, погашение из поступлений |
| **ВКЛ / НКЛ** | Возобновляемая / невозобновляемая кредитная линия |
| **Лизинг** | Финансовая аренда с выкупом. Плюсы для ООО на ОСН: вычет НДС, ускоренная амортизация, имущество само служит обеспечением |
| **Факторинг** | Финансирование под дебиторскую задолженность (отсрочки платежа от покупателей) |
| **Банковская гарантия** | Обязательство банка заплатить за клиента. Нужна в госзакупках (обеспечение заявки, исполнения, аванса) |
| **44-ФЗ / 223-ФЗ** | Законы о госзакупках и закупках госкомпаний |
| **Корпорация МСП** | Госинститут поддержки МСП: льготные программы кредитования, поручительства |
| **Зонтичное поручительство** | Поручительство Корпорации МСП, покрывает до 50% кредита. Позволяет получить кредит без своего залога |
| **РГО** | Региональные гарантийные организации: поручительства на региональном уровне |
| **ЕГРЮЛ / ЕГРИП** | Госреестры юрлиц и ИП (ФНС) |
| **ГИР БО** | Госинформресурс бухотчётности (bo.nalog.ru). ИП бухотчётность не сдают |
| **ФССП** | Служба судебных приставов: исполнительные производства (долги по решениям суда) |
| **ЕФРСБ / Федресурс** | Реестры банкротств и существенных фактов деятельности юрлиц |
| **ЕИС** | Единая информационная система в сфере закупок (zakupki.gov.ru) |
| **РНП** | Реестр недобросовестных поставщиков |
| **БКИ** | Бюро кредитных историй (НБКИ, ОКБ, Скоринг Бюро и др.). Запрос кредитной истории возможен только с согласия клиента |
| **ЗСК** | Платформа Банка России «Знай своего клиента»: присваивает юрлицам и ИП уровень риска по 115-ФЗ (низкий, средний, высокий) |
| **115-ФЗ** | Закон о противодействии отмыванию денег. Причина блокировок счетов |
| **152-ФЗ** | Закон о персональных данных |
| **ОФД** | Оператор фискальных данных: через него проходят все чеки онлайн-касс |
| **СБП** | Система быстрых платежей. Для бизнеса — оплата по QR |
| **Эквайринг** | Приём оплаты картами. Банк возмещает выручку обычно раз в день одной суммой |
| **Open API (открытые API)** | Стандарт Банка России для обмена данными о клиенте между финорганизациями с его согласия. Обязателен для крупнейших банков с 2026 года |
| **ЕНС / ЕНП** | Единый налоговый счёт / единый налоговый платёж |
| **УСН / ПСН / АУСН / ОСН / ЕСХН** | Налоговые режимы: упрощёнка, патент, автоматизированная УСН, общий режим, сельхозналог |

## Техника

| Термин | Смысл |
|---|---|
| **grpc-gateway** | Генерирует из `.proto` REST/JSON-прокси к gRPC-сервису |
| **protoc** | Компилятор `.proto`. Плагины (`protoc-gen-go`, `protoc-gen-go-grpc`, `protoc-gen-grpc-gateway`, `protoc-gen-openapi`) генерируют код. buf в проекте не используем ([ADR-0001](../03-architecture/adr/0001-monorepo-contract-first.md)) |
| **SSE** | Server-Sent Events: однонаправленный стрим событий сервер → браузер по HTTP |
| **sqlc** | Генерирует типобезопасный Go-код из SQL-запросов |
| **River** | Очередь фоновых задач для Go поверх Postgres |
| **Tool calling** | Механизм, при котором LLM не отвечает текстом, а просит вызвать функцию с аргументами |
| **Генеративный UI** | Ответ ассистента содержит не только текст, но и структурированные виджеты, которые фронт рендерит компонентами |
| **RAG** | Retrieval-Augmented Generation: перед ответом ищем релевантные куски базы знаний и подставляем их в промпт |
| **pgvector** | Расширение Postgres для векторного поиска |
| **SHAP** | Метод объяснения предсказаний модели: вклад каждого признака |
| **Контрфактическое объяснение** | «Что должно измениться, чтобы решение стало другим» |
| **Калибровка** | Приведение выхода модели к реальной вероятности (isotonic / Platt) |
| **OpenAI-compatible API** | Протокол `/v1/chat/completions`. Его поддерживают Ollama, vLLM, LM Studio и большинство провайдеров |
