## Допущения

Это решения по умолчанию. Если что-то из этого неверно, скажите.

1. **Фиксированная «сегодняшняя» дата демо-мира**: `DEMO_TODAY=2026-10-06`. Вся синтетика (транзакции за 24 месяца назад, прогноз вперёд) строится относительно неё. Это делает демо воспроизводимым.
2. **Ставки и лимиты в каталоге — демо-параметры** по мотивам публичных условий, а не оферта. Базовая ставка привязана к ключевой ставке ЦБ из конфига (`KEY_RATE`).
3. **Деньги хранятся в копейках (`int64`)**, никаких `float` для сумм.
4. Клиент — это ИП или ООО. У одного телефона один бизнес (мульти-бизнес не делаем).
5. Интерфейс на русском, вёрстка desktop-first: дизайн под 1280px. Адаптив только базовый.
6. Чат хранит историю. Ассистент видит только агрегаты по клиенту, сырые транзакции в LLM не попадают.
7. Продуктивные интеграции (ФНС, БКИ, ОФД, маркетплейсы, Open API банков) эмулируются mock-адаптерами с реалистичными данными.
