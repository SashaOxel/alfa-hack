# Сценарий защиты

Тайминг рассчитан на ~6 минут демо. Точный формат защиты пока неизвестен (открытый вопрос Q1 в [decisions.md](../00-overview/decisions.md)), сценарий легко сжать до 3 минут: см. блоки ★.

## Подготовка

- [ ] `make demo-reset` за 10 минут до выступления
- [ ] LLM прогрета: выполнить 1 тестовый запрос (иначе первая генерация медленная)
- [ ] Две вкладки: кабинет (кофейня) и кабинет (салон) в инкогнито
- [ ] Записанное видео всего сценария как запасной план
- [ ] Отключены уведомления ОС, масштаб браузера 100%, разрешение 1280–1440px

## Сценарий

| Время | Что делаем | Что говорим (суть) |
|---|---|---|
| 0:00 ★ | Слайд с проблемой | «Предприниматель не знает, какой кредит ему нужен, а банк знает о его бизнесе больше, чем любая анкета» |
| 0:20 ★ | Вход по телефону кофейни, код из SMS-тоста | «Александр, владелец кофейни. Никаких анкет» |
| 0:35 ★ | Главная: баннер «доступно до 3,5 млн», **алерт о кассовом разрыве через 23 дня** | «Банк сам увидел рост +18% и что в конце октября будет минус: закупка зерна, налог и конец сезона веранды. Овердрафт уже рассчитан» |
| 1:05 ★ | Чат: «хочу вторую кофемашину и пополнить запасы, около 2 млн» | «Ассистент понимает задачу, а не ключевые слова». Справа заполняется «Что я понял» |
| 1:30 ★ | В чате появляются **карточки офферов**, затем «сравни с лизингом» | «Ассистент отвечает интерфейсом. Обратите внимание: все цифры из расчётов, а не от нейросети» |
| 2:10 | Включаем «Как думает ассистент» | Видны вызовы инструментов: профиль бизнеса → подбор офферов → калькулятор. «LLM — интерфейс, решения принимает модель и правила» |
| 2:35 | «Финансы → Данные и согласия» → подключить ОФД | «Клиент контролирует данные. Подключил кассу — лимит вырос, ставка снизилась» |
| 3:00 ★ | «Оформляй» → черновик заявки, 80% полей заполнено → загрузка счёта (P1) → поставщик проверен | «Поля заполнены из выписки и ЕГРИП. Из счёта вытащили поставщика и проверили его» |
| 3:40 ★ | «Отправить» → **живой таймлайн** → «Одобрено» за ~20 с | «Решение за секунды. Почему одобрено — факторы модели простым языком» |
| 4:15 ★ | Подписать → SMS-код → «Деньги на счёте» → главная: остаток +2 млн | «От идеи до денег — 4 минуты» |
| 4:35 | Вкладка «Салон»: запрос 1,5 млн | «А вот честный отказ: МФО, недоимка, приставы. Но клиент получает встречное предложение и план, как получить одобрение через 3 месяца» |
| 5:15 | (Опционально) IT-студия: бейдж «Господдержка: экономия 312 000 ₽» | «Ассистент сам находит льготные программы» |
| 5:30 ★ | Слайд архитектуры | On-prem open-source LLM, данные не покидают контур. Источники данных и LLM за адаптерами, на прод переносится заменой адаптеров. Roadmap: Open API, ОФД, маркетплейсы |

## Вопросы жюри, к которым готовимся

| Вопрос | Ответ (суть) | Где детали |
|---|---|---|
| «А если LLM ошибётся с цифрой?» | LLM не считает. Цифры берутся из инструментов, а guardrail сверяет каждое число в ответе с результатами инструментов | [ai-assistant.md](../03-architecture/ai-assistant.md#guardrails) |
| «Модель обучена на синтетике, что она стоит?» | Мы показываем пайплайн и объяснимость. Генератор заложен так, что можно проверить, восстанавливает ли модель известную зависимость. Реальные данные подключаются адаптером без изменений кода | [models.md](../05-ml/models.md) |
| «Как с персональными данными?» | On-prem LLM, маскирование PII, если провайдер внешний, согласия по 152-ФЗ и 218-ФЗ, аудит действий ассистента | [security.md](../03-architecture/security.md) |
| «Почему не Kafka и микросервисы?» | Для 2 недель и 5 человек это оверхед. Показываем путь до прода | [overview.md](../03-architecture/overview.md#путь-в-прод) |
| «Чем вы лучше Альфа-Интеллекта?» | Мы не конкуренты, а кредитный агент для этой экосистемы. Прогноз кассового разрыва есть в их планах, у нас он работает и сразу превращается в оффер | [market.md](../01-research/market.md) |
| «Как это масштабировать?» | Stateless core и ml, LLM-кластер на vLLM, feature store из DWH | [overview.md](../03-architecture/overview.md#путь-в-прод) |

## Риски на демо

| Риск | Что делаем |
|---|---|
| LLM тормозит или отвечает странно | Модель прогрета. Фразы для демо прогнаны в eval. Режим `AGENT_MODE=router` как запасной. Видео |
| Нет интернета | Всё локально (docker compose + Ollama). Внешних вызовов нет |
| Сломалось состояние демо-мира | `make demo-reset` (≤ 10 с) |
| Не успели P1-фичу | Сценарий сжимается до блоков ★ |
