# Демо-персоны

Персоны нужны, чтобы жюри увидело: **рекомендации разные, потому что разные данные**. Каждая персона — это сценарий в генераторе синтетики ([data-generation.md](../05-ml/data-generation.md)) со своими событиями в транзакциях. На каждую заведён свой номер телефона для входа.

> Все персоны вымышлены, совпадения случайны.

### 1. Кофейня «Зерно», ИП Смирнов Александр Игоревич

Главная персона, совпадает с дизайном.

| | |
|---|---|
| Профиль | ИП с 14.03.2024, УСН 6%, 6 сотрудников, Иркутск (регион по ИНН 38…), ОКВЭД 56.30 |
| Деньги | Выручка ~1,28 млн ₽/мес: эквайринг 85%, СБП 15%. Остаток ~640 тыс. ₽. Рост +18% за квартал (открыли летнюю веранду) |
| Расходы | Поставщики зерна и молока (~35%), ЗП 2 раза в месяц + НДФЛ, аренда 120 тыс. ₽, ЕНП ежеквартально, кредит в нашем банке (платёж ~150 тыс. ₽ → нагрузка 12%) |
| Скрытые события | Сентябрь: предоплата 10% поставщику кофемашин (сигнал capex). Конец октября: квартальная закупка зерна (регулярный платёж, его находит прогноз) + авансовый платёж по УСН 28.10 + закрытие летней веранды (−15% выручки) → **прогноз разрыва ~180 тыс. ₽ 29 октября, через 23 дня** |
| Что показываем | Проактивный баннер «вам доступно до 3,5 млн». Диалог «вторая кофемашина + запасы, ~2 млн». Сравнение кредита на оборудование и лизинга. Овердрафт под запасы. Подключение ОФД → лимит выше. Заявка → одобрение → подписание → деньги |
| Ожидаемые офферы | `equipment_loan` 2 млн / 36 мес (лучший), `leasing` (альтернатива), `overdraft` под разрыв, `biz_loan` |

## Как персоны используются в разработке

- Генератор синтетики создаёт персоны **детерминированно** (фиксированный seed + скриптованные события), плюс фон из сотен случайных клиентов для обучения моделей.
- Для каждой персоны есть **golden-файл ожидаемых результатов** (`ml/datagen/personas/<id>.expected.yaml`): какие офферы в топ-3, какие сигналы сработали, какие стоп-факторы. Это интеграционный тест: «поменяли модель — офферы кофейни не поехали».
- `make demo-reset` возвращает демо-мир в исходное состояние: удаляет заявки и чаты, восстанавливает балансы.
