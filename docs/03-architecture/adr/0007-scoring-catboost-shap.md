# ADR-0007: Скоринг CatBoost + SHAP, решение не принимает LLM

- **Статус:** принято
- **Дата:** 2026-10-06

## Контекст
Нужно показать «ИИ-скоринг» и объяснимость («Почему одобрено»). Реальных данных о дефолтах нет. Задача — продать концепт, а не выиграть Kaggle.

## Решение
- **PD-модель**: CatBoostClassifier на признаках из `ClientDataBundle`. Таргет — синтетический дефолт за 12 мес, сгенерированный известной функцией от скрытых факторов + шум. Калибровка: isotonic.
- **Вероятность одобрения**: логистическая регрессия поверх `[PD, платёж / FCF, сумма / лимит, продукт]`. Обучена на синтетических заявках, размеченных синтетической политикой андеррайтинга с шумом.
- **Объяснения**: SHAP (встроенные `ShapValues` CatBoost) → топ-факторы → словарь человеческих формулировок.
- **Решение по заявке** принимает Go-политика (пороги, лимиты, стоп-факторы) на основе выхода моделей. LLM в решении не участвует.
- Артефакты версионируются (`artifacts/pd/<version>/`), у каждой модели есть model card.

## Альтернативы
| Вариант | Плюсы | Минусы |
|---|---|---|
| Только правила | Быстро | Слабо для ML-части оценки, нет SHAP |
| LLM оценивает риск | Модно | Необъяснимо, недетерминированно, регуляторно неприемлемо |
| Сложный ансамбль / нейросеть | Красиво | Нет данных, на которых это имеет смысл |

## Последствия
- На защите честно говорим: модель обучена на синтетике. Показываем, что пайплайн восстанавливает заложенную зависимость (сравнение SHAP с истинными весами генератора) и что реальные данные подключаются адаптером.
