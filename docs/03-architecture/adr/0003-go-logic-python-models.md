# ADR-0003: Вся бизнес-логика в Go, Python — только работа с моделями

- **Статус:** принято (решение капитана)
- **Дата:** 2026-10-06

## Контекст
Стек: Go (бэкенд) и Python (ML). Нужна жёсткая граница, иначе логика размажется по двум языкам: правила продукта окажутся в Python, а их дубли — в Go. Команда: 1 fullstack, 1 junior на Go, 3 ML.

## Решение
**Python отвечает только за модели.**

| | Go (`core`) | Python рантайм (`ml`) | Python офлайн |
|---|---|---|---|
| Что | Доступ к данным, согласия, движок офферов (стоп-факторы, лимиты, ставки, калькуляторы, ранжирование, what-if), заявки, документы, **ИИ-агент** (LLM-вызовы, инструменты, RAG, guardrails), SSE | Stateless-инференс: `ClientDataBundle` → признаки → PD, калибровка, SHAP, вероятность одобрения; прогноз cash flow; категоризация транзакций | Генерация обучающих данных, обучение, оценка моделей, eval LLM |
| БД | Единственный, кто ходит в Postgres в рантайме | Нет | datagen пишет `bank.*` при загрузке |
| LLM | Вызывает LLM напрямую (OpenAI-совместимый API) | Нет | eval через REST core |

Контракт между ними — `ClientDataBundle` (proto). Go собирает его из БД с учётом согласий, Python превращает его в признаки **тем же кодом (`mlcore`), что и при обучении**.

What-if и контрфакты: Go формирует сценарии (другая сумма, срок, допущение «недоимка погашена», «подключён ОФД»), Python скорит их батчем. Правила, **какие** сценарии строить и что из них показывать, живут в Go.

## Альтернативы
| Вариант | Плюсы | Минусы |
|---|---|---|
| Агент и движок офферов в Python | Нагрузка смещается на 3 ML-инженеров | Бизнес-логика в двух языках; Python-сервис с доступом к БД; циклические вызовы core ↔ assistant |
| ML-сервис сам читает БД и считает признаки | Меньше работы Go | Python знает схему БД и согласия, граница размыта |

## Последствия
- ➕ Чистая граница: ML-сервис тестируется подачей бандла, без БД.
- ➕ Агент вызывает Go-модули in-process: нет сетевых хопов и циклических зависимостей, цифры в чате и на экранах совпадают.
- ➖ **Нагрузка на Go-сторону растёт**: агент и движок офферов пишет fullstack. Меры: junior забирает SQL сборки бандла, согласия, документы, notify. ML-LLM владеет промптами, описаниями инструментов, базой знаний и eval. Фронт и ML разблокированы фейками (`mlclient.fake`, моки API).
- ➖ Риск расхождения бандла из Postgres (Go) и из parquet (Python). Мера: контрактный тест на golden-бандлах персон.
